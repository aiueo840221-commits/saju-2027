# 🔮 2027 정미년 신년 사주 (saju-2027)

생년월일(시)만 입력하면 2027 정미년(丁未年, 붉은 양의 해) 운세를 한 장의 카드로 보여 주는 웹앱입니다.

**바로 사용하기**: https://aiueo840221-commits.github.io/saju-2027/

## 특징
- 실제 만세력 계산: 일주(60갑자), 년주(입춘 기준), 월주(태양 황경 12절 기준), 시주, 오행 분포 — 순수 클라이언트 JS, 외부 API 없음
- 2027년 운세: 정미년 丁(화)·未(토)와 내 일간의 십성 관계로 총운·재물운·연애/대인운·일·사업운·건강운 (일간 10종 × 띠 관계 × 오행 구성별 다른 해석)
- 결과 카드 이미지 저장(HTML5 Canvas → PNG), 결과 공유 링크 복사
- 다크 네이비·골드·라일락 감성의 모바일 퍼스트 UI, PWA(홈 화면 추가) 지원, OG 태그 포함
- 입력한 정보는 서버로 전송되지 않고 브라우저 안에서만 계산됩니다

## 계산 방식 (검증)
- 일주: 1900-01-01 갑술(甲戌)일 기준, 경과일을 60으로 나눈 나머지 (1900~2100 전 기간 독립 데이터 73,414일과 대조 — 불일치 0)
- 년주/월주: 입춘(황경 315°) 등 12절의 절입 시각을 태양 겉보기 황경 천문 계산으로 판정
- 시주: 시두법(일간 기반), 자시 23:00~01:00

## 파일 구성
```
index.html  (분할 로더: gzip+base64 번들을 브라우저에서 조립)
s1.js~s6.js (번들 조각)
style.css, app.js  (원본 소스 — index.html 안의 번들과 동일 내용)
manifest.json, icons/
```
참고: 일부 호스팅 환경의 개별 .js/.css 파일 요청 실패에 대비해 index.html에 번들을 내장했습니다(app.js·style.css는 원본 소스이며 직접 참조하지 않습니다).
